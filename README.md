# 🏋️ Fitness Club Analytics Dashboard | Power BI

## 📌 Project Overview

An interactive **Fitness Club Analytics Dashboard** developed using Microsoft Power BI to analyse membership trends, customer acquisition, revenue, expenses, profitability, and member health metrics.

This project focuses on transforming fitness club data into meaningful business insights through interactive visualisations, dynamic titles, DAX calculations, and user-friendly report navigation.

The project was completed as part of my self-learning journey in Power BI, following a practical tutorial and implementing the concepts through hands-on practice.

## 🎯 Project Objectives

- Analyse monthly member acquisition and membership growth.
- Monitor active and expired memberships across different membership categories.
- Track revenue, expenses, and profit trends.
- Understand member demographics through age and gender analysis.
- Explore BMI and fitness-related metrics.
- Build an interactive dashboard with dynamic filtering and calculations.

## 📊 Dashboard Pages & Features

### 1. Home Page
- Interactive landing page for dashboard navigation.
- Easy access to different analytical sections.

### 2. Overall Dashboard
- **Membership Overview:** Monitor total members and membership categories.
- **Membership Analysis:** Analyse active and expired memberships across Silver, Gold, and Platinum categories.
- **Monthly Member Acquisition:** Track monthly membership trends using a column chart.
- **Financial Performance:** Analyse monthly revenue, expenses, and profit.
- **Latest Data Refresh:** Display the last refresh date dynamically.

### 3. Members Dashboard
- Member-level details and membership information.
- Age category analysis segmented by gender.
- Member distribution by membership status.
- BMI and demographic analysis.
- Interactive filters for exploring member information.

### 4. Fitness Calculator
- BMI calculation and visualisation.
- TDEE (Total Daily Energy Expenditure) analysis.
- Daily calorie requirements for maintaining weight.
- Calorie recommendations for different weight-loss goals.
- Interactive weight and height inputs.

## 🛠️ Technical Skills & Implementation

### 1. DAX (Data Analysis Expressions)

Applied DAX to develop dynamic calculations and improve dashboard interactivity.

**DAX Functions Practised:**

- `CALCULATE()` – Evaluate expressions under modified filter contexts.
- `SWITCH(TRUE())` – Implement multiple conditional logic scenarios.
- `IF()` – Apply conditional calculations and logical tests.
- `MAXX()` – Evaluate expressions across a table and return the maximum value.
- `MINX()` – Evaluate expressions across a table and return the minimum value.
- `SELECTEDVALUE()` – Retrieve the currently selected value from a column.
- `DATEDIFF()` – Calculate the difference between two dates.
- `DIVIDE()` – Perform division with safe handling of division-by-zero scenarios.

### 2. Dynamic Dashboard Features

- **Dynamic Title Colour:** Applied conditional formatting to change title colours dynamically based on selection and defined conditions.
- **Dynamic Refresh Date:** Displayed the latest data refresh date using DAX.
- **Dynamic Maximum & Minimum Selection:** Implemented maximum and minimum value selection within the monthly member acquisition bar chart to focus on specific data points.
- **Interactive Filtering:** Used slicers and visual interactions to explore data across different categories.
- **Conditional Logic:** Applied SWITCH(TRUE()) and IF() to create flexible analytical measures.
